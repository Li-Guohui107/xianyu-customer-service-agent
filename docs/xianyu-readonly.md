# 闲鱼网页回复的手动测试

自动回复操作的是你自己已经登录的闲鱼网页。它不读取 Cookie，也不把登录目录提交到 Git。

## 没有账号时也可以检查的部分

1. 运行 `.\.venv\Scripts\python.exe -m pytest`。测试里的服务不会启动浏览器。
2. 客服页仍可以粘贴一段对话，用来核对草稿：

```text
买家: 这个机器学习大概多少钱
客服: 稍等
买家: 用 sklearn 吗
```

3. 点击「识别买家消息」。输入框里应只剩下买家的话。
4. 问价格的草稿不出现金额，只给出本机 `.env` 里的微信号。
5. 买家要求包过、代写论文、代考或替交时，发出去的句子必须是拒绝。

## 用自己的闲鱼网页试回复

1. 启动服务：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8011
```

2. 如果调试端口还没开，程序会用 `browser-profile/` 打开 Chrome 或 Edge。在这个窗口打开 <https://www.goofish.com/> 并自己登录，再进入 <https://www.goofish.com/im>。
3. 登录成功后不要关闭这个窗口。停掉服务不会关闭它。
4. 打开 <http://127.0.0.1:8011/>，顶部应显示已经连上闲鱼网页。
5. 用另一个账号在当前会话发一条新消息。打招呼和问价格应很快出现回复；其他问题会等模型写完再发送。
6. 同一句话再发一次，也应再收到一条回复。
