# 闲鱼只读接入的手动测试

当前版本不会登录闲鱼，不会读取 Cookie，也不会点击发送。买家消息由客服从自己已经打开的闲鱼页面复制进来。

## 没有账号时也可以检查的部分

1. 启动服务后打开客服页。
2. 在「从闲鱼复制的对话」中粘贴：

```text
买家: 这个机器学习大概多少钱
客服: 稍等
买家: 用 sklearn 吗
```

3. 点击「识别买家消息」。输入框里应只剩下两句买家的话，客服那一行不会留下。
4. 在底部输入买家说的话并发送。黄底草稿出现在右侧，复制后由你自己发到闲鱼。
5. 运行 `python -m pytest tests/test_xianyu.py`。浏览器连接器在未启用时应直接失败，并提示改用粘贴。

## 使用自己的闲鱼页面时

1. 在你自己的浏览器中打开闲鱼并完成登录。不要把 Cookie、用户目录或截图中的登录信息交给本仓库。
2. 复制买家刚发来的文字，粘贴到客服页。
3. 核对商品是否匹配、风险标记是否合理。
4. 需要回复时，由你自己复制草稿，回到闲鱼手动发送。

`XIANYU_BROWSER_USER_DATA` 即使填了本地目录，程序也会忽略它，避免误开页面或误读登录态。自动读取页面需要以后单独确认，再决定是否引入浏览器工具。
